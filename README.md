# Дядя Витя и тихий берег

**Атмосферный ночной платформер в одном действии.**  
Дядя Витя три года не пьёт, но должен Борисычу сорок семь тысяч. На двери висит записка: «Три дня». В сарае стоит отцовский медный чан, а в тетради — рецепт медовухи. Значит, пора варить.

**▶ Играть онлайн: [yakimak.github.io/dyadya-vitya](https://yakimak.github.io/dyadya-vitya/)**  
Играть можно прямо в браузере — скачивать ничего не нужно.

![Титульный экран](preview/title.png)

## Что внутри

- один цельный уровень: двор, яблоневый сад с ульями, переправа по плотам, хмелевая роща и пивоварня;
- четыре персонажа с диалогами и своими характерами: Борисыч, баба Зина, Стас и Гриша;
- девять ингредиентов: хмель, мёд и вода;
- контрольные фонари, движущиеся плоты, сбор предметов, финальная варка;
- сюжетная заставка, финал и титры;
- полностью процедурная графика: ночное небо, туман, светляки, дым, листва, вода и свет;
- атмосферная музыка: бесплатные эмбиент-лупы из [ncase/wbwwb](https://github.com/ncase/wbwwb) + оригинальная генеративная партитура на Web Audio.

## Запуск

### Windows

1. Установите Python 3, если его ещё нет.
2. Дважды щёлкните `start.bat`.
3. Браузер откроет `http://localhost:8000/`.

### Вручную (любая ОС)

```bash
cd Game2
python -m http.server 8000
```

Затем откройте <http://localhost:8000/>.

> Важно: запускайте игру через локальный сервер, а не двойным щелчком по `index.html`.  
> При открытии через `file://` браузер может заблокировать загрузку звука и шрифтов.

Рекомендуется Chrome, Edge или Firefox и наушники. Звук включается после первого клика — так требует браузер.

## Управление

| Клавиша | Действие |
|---|---|
| `A` / `D` или `←` / `→` | идти |
| `Пробел` / `W` / `↑` | прыжок |
| `E` / `Enter` | говорить, читать, варить |
| `R` | вернуться к последнему фонарю |
| `Esc` | пауза |
| `M` | звук вкл/выкл |
| `F` | на весь экран |

Во время диалога `E`, `Пробел` или `Enter` листают реплики. Кнопкой мыши тоже можно листать.

## Цель

Собрать **три хмеля**, **три сота мёда** и **три бутылки ключевой воды**, поговорить с Борисычем у пивоварни и сварить медовуху в медном чане. Фонари на пути работают как контрольные точки.

## Музыка и атмосфера

- `audio/bg_nighttime.mp3`, `audio/bg_park.mp3`, `audio/crickets.mp3` — бесплатные атмосферные звуки из проекта **ncase/wbwwb** (CC0).
- Оригинальная музыка — процедурная партитура на Web Audio API: тёплые пэды, бас, музыкальная шкатулка, реверберация. Мелодия меняется между ночью и финалом.
- Звуковые эффекты — синтез Web Audio: прыжки, шаги, вода, колокольчики, варка.

## Технологии

| Что | Где |
|---|---|
| [PixiJS 4.8.9](https://pixijs.com/) — рендер, сцена, свет | `lib/pixi.min.js` |
| [Howler.js](https://howlerjs.com/) — эмбиент и сэмплы | `lib/howler.js` |
| Web Audio API — генеративная музыка и SFX | `js/audio.js` |
| Cormorant Garamond, Alegreya Sans | `fonts/` (SIL OFL) |
| Вся графика | `js/art.js`, `js/world.js` — нарисована кодом |

### Структура

```
index.html          точка входа
css/style.css       экран загрузки и фон страницы
fonts/              локальные шрифты (Cyrillic + Latin)
lib/                PixiJS и Howler
audio/              эмбиент из wbwwb
js/utils.js         палитра, математика, текстуры, ввод
js/audio.js         музыка, эмбиент, звуки
js/art.js           избы, берёзы, ульи, персонажи, портреты, чан
js/world.js         уровень, параллакс, свет, река, NPC, предметы
js/entities.js      Витя, NPC, фонари, ингредиенты
js/ui.js            титул, HUD, диалоги, заставки, пауза, титры
js/game.js          состояния, камера, физика, сюжет, финал
```

## Для разработчика

Отладочные сцены (только для проверки, в обычной игре не нужны):

```
?debug=1&scene=play&x=1800
?debug=1&scene=story
?debug=1&scene=brew&frames=150&freeze=1
?debug=1&scene=ending&frames=320&freeze=1
```

`freeze=1` останавливает время, чтобы удобно рассматривать кадр.  
`frames=N` прокручивает N кадров до отрисовки.
